# Mini Data Analysis Tool

A beginner-friendly Python project built using NumPy for analyzing CSV datasets.

This project loads sales data from a CSV file and performs basic data analysis like:

* Total sales
* Average sales
* Highest and lowest sales
* Sales trend analysis
* Filtering high sales values

---

# 🚀 Features

* Load CSV data using NumPy
* Analyze sales statistics
* Detect increasing/decreasing trends
* Filter sales above a certain value
* Beginner-friendly code structure

---

# 🛠️ Technologies Used

* NumPy
